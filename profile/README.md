# HighSpeed.gg

Welcome to the official GitHub organization for **HighSpeed.gg** — the home of high-energy Assetto Corsa "cut up" servers!  
Here you'll find the projects, tools, and custom server logic that power the [HighSpeed.gg](https://highspeed.gg) community.

---

## 🚗 What is HighSpeed.gg?

**HighSpeed.gg** is a community-driven Assetto Corsa server focused on delivering the most authentic "cut up" and freeroam experience. Our servers are purpose-built with advanced traffic handling, and custom backend features — all designed for smooth, stable, and truly unique multiplayer sessions.

- **Cut Up Traffic Handling:** Advanced custom logic lets you weave through dense traffic, just like those viral street runs.
- **Custom Server Logic:** Engineered for stability and performance, with features tailored to the needs of the HighSpeed.gg community.

---

## 🛠️ Open Source Projects

We maintain and improve our own fork of [AssettoServer](https://github.com/compujuckel/AssettoServer), as well as supporting tools and integrations for the best possible server experience.  
Browse our repositories for:

- Custom server builds for Assetto Corsa
- Traffic and gameplay logic
- Automation tools
- Backend services and API integrations

---

## 🎮 What does "Cut Up" mean?

*"Cut up"* describes the driving style of threading the needle through traffic at speed, weaving between AI and real drivers for a thrilling, challenging experience — inspired by viral street runs and real-world car culture.
